# Tudy – Backend

## Study with Tudy

### Описание

Backend частта на Tudy представлява REST API, разработено с Node.js и Express.js.

Системата отговаря за управлението на потребителски акаунти, събития, учебни планове, статистики и комуникацията с MongoDB базата данни.

---

## Основни функционалности

### Управление на потребителски акаунти

Поддържат се:

- регистрация;
- вход;
- имейл верификация;
- възстановяване на забравена парола;
- смяна на парола;
- смяна на потребителско име;
- излизане от акаунт
- изтриване на акаунт.

### Управление на събития

Системата поддържа:

- учебни събития;
- лични събития.

### Автоматично генериране на учебен план

При създаване на учебно събитие се генерира учебен план.

Алгоритъмът:

1. Анализира съществуващите събития на потребителя.
2. Определя свободните времеви интервали.
3. Работи в интервал от 08:00 до 22:00 часа.
4. Разделя свободното време на учебни сесии.
5. Разпределя страниците спрямо наличното време.
6. Избягва конфликти с вече съществуващи събития.
7. Генерира повторения след 2, 4 и 7 дни.

### Статистики

Системата предоставя информация за:

- общ брой събития;
- предстоящи събития;
- общо време, прекарано във фокус режим (времето за учене);
- учебно време по дни за текущата седмица.

## Стартиране на проекта

Инсталиране на зависимостите:

```bash

```

```bash
npm run dev
```

```bash
brew services start mongodb-community@7.0
```
